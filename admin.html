🔑 Konfigurasi GitHub
Token GitHub diperlukan untuk upload file dan update index.html secara otomatis.

⚠️ Gunakan Classic Token, bukan Fine-grained!
Buka: GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
Klik "Generate new token (classic)", centang scope: repo (full control).

Format token yang benar dimulai dengan ghp_ — bukan github_pat_.
✅ Token hanya disimpan di localStorage browser ini, tidak dikirim ke server manapun selain GitHub API.
